# Obligation Tracker

A tiny, self-hosted web app to track recurring obligations (bills, EMIs, subscriptions) and send email reminders.

- Backend: Node.js + Express  
- Frontend: React (Vite)  
- DB & Auth: Supabase (Postgres + Supabase Auth)  
- Infra: Docker + Docker Compose on Ubuntu  
- Email: SMTP
